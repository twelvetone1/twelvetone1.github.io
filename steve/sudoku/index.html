Chain Mode

Forcing Chain

A forcing chain tests two candidate digits of a cell simultaneously. If one branch leads to a contradiction, the other must be true.

How to use:

1. Long-press a cell with 2 or 3 pencil marks to start.
2. Tap that cell, then tap a digit — it becomes Branch A (orange).
  • 2-mark cell: Branch B is auto-assigned the other digit.
  • 3-mark cell: tap the start cell again and pick a digit for Branch B.
3. Tap any cell on the board to select it, then tap a digit to extend the active branch.
4. Use the A / B buttons in the banner to switch which branch you are extending.
5. Strikethrough pencil marks show candidates eliminated by a branch's assignments.
6. Red border — a branch eliminates all candidates in that cell; it leads to a contradiction.
7. Green border — both branches place the same digit in a cell; tap it to confirm and place the digit.

Undo Link removes the last step of the active branch. Cancel exits chain mode.
